# 픽셀 스프라이트

**바로 쓰기 → https://jujeongmin.github.io/pixel-sprite/**

게임용 픽셀아트와 프레임 애니메이션을 그려서 PNG 스프라이트 시트로 내보내는 도구.
파일 하나(`index.html`)로 돈다. 설치도 서버도 없고, 작업은 브라우저에 자동 저장된다.

## 기능

- **캔버스** 1~256칸 (기본 32×32), 칸 선(8칸마다 진하게), 휠로 확대
- **도구** 연필 · 지우개 · 채우기 · 스포이드 · 직선 · 사각형(테두리/채우기) · 옮기기 · 좌우 대칭
- **색** 왼쪽 클릭 / 오른쪽 클릭에 각각 색. 오른쪽은 처음에 투명이라 우클릭이 곧 지우개
- **팔레트** Sweetie 16 · PICO-8 · Endesga 32 · 게임보이 · 흑백 8 · 내 팔레트(그림에서 색 뽑기 가능)
- **애니메이션** 프레임 추가·복제·순서 바꾸기, 앞 프레임 겹쳐 보기, fps 조절 미리보기
- **내보내기** 스프라이트 시트(가로로 이어 붙임) · 현재 프레임 · 프레임 전부, 배율 1~16배
- **불러오기** PNG 열기 / 끌어다 놓기. 가로로 긴 그림은 시트로 보고 프레임으로 나눌지 묻는다

## Unity 에 넣기

1. **배율 1** 로 [시트 저장] → `sprite_32x32_4f.png` 처럼 칸 크기·프레임 수가 이름에 붙는다
2. Texture Type `Sprite (2D and UI)`, Sprite Mode `Multiple`, Filter Mode `Point`, Compression `None`
3. Sprite Editor → Slice → `Grid By Cell Size` 에 칸 크기(예: 32×32) → Apply

## 단축키

| 키 | 동작 |
|---|---|
| `B` `E` `G` `I` `L` `R` `V` | 연필 · 지우개 · 채우기 · 스포이드 · 직선 · 사각형 · 옮기기 |
| `M` / `X` | 좌우 대칭 / 두 색 바꾸기 |
| `Alt`+클릭 | 스포이드 |
| `,` `.` | 앞 · 뒤 프레임 |
| `Ctrl+Z` / `Ctrl+Shift+Z` | 되돌리기 / 다시 |
| `Ctrl+S` | 시트 저장 |
| 휠 / `스페이스`+드래그 | 확대 / 이동 |
